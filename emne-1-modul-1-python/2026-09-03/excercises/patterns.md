# Oppgaver – mønstre med for-løkker

Lag for-løkker som skriver ut mønstrene nedenfor.

## Tips

For å skrive ut tekst uten å begynne på en ny linje kan du bruke:

```python
# print same line
print("*", end="")

# print start of same line
print("*", "\r")
```

For å begynne på en ny linje kan du bruke:

```python
print()
```

Du vil sannsynligvis ha behov for å bruke **løkker inni løkker**.
